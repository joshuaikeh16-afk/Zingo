# Product-quality pass — 2026-10-04

Audit: vanilla HTML/CSS/ES modules, hash routing, shared modal/focus manager and Supabase client. Auth/profile onboarding and the existing DM/group, polls, receipts, private library and PWA systems are already connected. Production uses TMDB, football-data.org and BBC RSS; no games provider is configured. Discover currently reuses personalised catalog queries, Football is a flat fixture list, reactions inherit generic mobile bottom-sheet styles, and only chat responds to VisualViewport.

Live schema audit: migrations 20261003–20261008 exist; no battles, relationships or match-support tables exist. `user_watchlist` remains owner-only. `user_preferences` already contains messaging/privacy flags. `app_notifications.event_key` currently references only `sports_events`, so multi-category notifications need a compatible extension that preserves football event references and deduplication.

Order: (1) shared keyboard-safe sheets and compact reactions; (2) independent provider-backed Discover routes, banners and filters; (3) Jikan genre/theme/season archive alongside TMDB movie/series taxonomies; (4) football sections, provider-verified match snapshots and per-match support; (5) private social preferences and deduplicated friend recommendations; (6) conversation-linked opinion challenges/votes/progression; (7) mutually consensual relationships with the most restrictive visibility of both parties; (8) Home/profile/notifications integration; (9) SQL/RLS, provider, realtime and responsive browser acceptance checks.

New migrations will be incremental, dry-run against the inspected schema with rolled-back fixtures, then applied before publishing dependent frontend changes. No production fixtures or invented content. Games, arbitrary anime themes, lineups and unsupported film styles remain hidden without reliable provider metadata. Opinion battles resolve by labelled social voting or concession, never by a claim of objective truth; no wagering or RPG engine.
